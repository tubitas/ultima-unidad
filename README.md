# Última Unidad — web del juego

Página de presentación de **Última Unidad**, el juego de llevar una tienda.
Estática, sin dependencias, publicada en GitHub Pages.

- Web: https://tubitas.github.io/ultima-unidad/
- Marcador: https://tubitas.github.io/uu-marcador/
- Fuente del juego y del diseño: iCloud `Tienda/proyectos/ultima-unidad-juego/`

## Reglas de la casa

- **Nada de marcas registradas** en ningún texto ni imagen. Las referencias del juego
  son alusiones (el cromo dorado, el pollo cuadrado, la langosta del almacén) y así
  deben seguir: si el juego se vende algún día, ahí es por donde se pincha.
- **Las placas legendarias no se explican.** En la web salen tres nombres y tres
  interrogantes, y ni una pista de cómo se consiguen. Es lo que las hace valer.
- Los enlaces de descarga **no son públicos**: el juego entero es un solo archivo HTML,
  así que publicarlo es regalarlo.
